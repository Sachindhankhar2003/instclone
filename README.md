# Instagram Clone

A simple, responsive, and interactive frontend clone of the Instagram web UI. Built using raw HTML, CSS, and vanilla JavaScript.

## Features implemented:
- Fully responsive design (Desktop layout, Tablet, Mobile layout with custom bottom-nav and header).
- Interactive Like buttons (supporting dynamic like counts).
- Post Save interaction.
- Double-tap a post image to like it, including a floating heart animation!
- Follow/Following button toggles.
- Story UI interface.

## Tech Stack
- HTML5
- CSS3 (Built with CSS variables and Media queries)
- JavaScript (Vanilla DOM interactions)
- Font Awesome Icons 

_Note: This project is strictly for learning and UI replication purposes._
